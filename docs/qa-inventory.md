# 本地验收范围

- 初始载入清空后的底图和六个字段，预览不请求渲染 API。
- 文字框右键属性浮窗，直接绑定字段；Shift + F10、Esc、外部关闭与窄边栏边界。
- 原图坐标拖动、缩放后拖动、右下角缩放手柄、方向键、撤销和重做。
- 切换记录、修改字段绑定、固定文字、字号、颜色、行距、斜体和对齐。
- 上传位图、上传 OTF 字体、无效字体拒绝，字体就绪后预览和导出一致。
- PNG 下载签名、尺寸、正文，以及本地示例附件写回与批量进度。
- 模板和素材保存、页面刷新、重新载入，持久化后预览和绑定不丢失。
- 窄边栏切换模板、画布和属性面板，控件可操作且无横向页面溢出。
- 数据层离线模拟飞书：模板 JSON/素材附件保存回读、输出附件字段写入、错误码、串行上传。
- 生产构建为静态 HTML/CSS/JS/素材，不含服务端 API、渲染密钥、Vercel Blob 或原生 resvg。

本地示例库使用浏览器 IndexedDB；飞书真机需要在多维表插件宿主中验证，离线模拟不能替代平台验收。

本轮追加验证：逐行底图、查找引用来源定位、来源模板与字体的保存/回读、切换记录和重开恢复、HEX/黑白字体颜色。来源记录无法唯一确定时拒绝保存，空底图或多附件不回退到固定底图。

新增表选择入口验证：先选择业务表再进入；配置表初始化成功后显示就绪；切换/取消、保存重开均正常。SDK 模拟测试覆盖多表字段同 ID 隔离、显式表读取、配置表首次创建/复用及权限/字段类型失败。

已有自建配置表复用：业务表与配置表分别选择。SDK 模拟验证只补配置字段、不 addTable；配置读写固定所选 ID，改选清缓存；权限、缺表和类型错误不得回退新建。旧表与原记录不删除。

固定连接与自动恢复：首次确认后保存 Base 范围内的双表 ID；刷新自动进入编辑器，配置行数不增长。SDK 模拟覆盖仓储重建、Base 隔离、权限错误与桥接回读失败。

旧绑定损坏回归：启动三项读取彼此独立，连接恢复失败不清空已读取表列表；通过选择原表修复后，刷新继续自动恢复。宿主空绑定与 JSON 文本绑定已覆盖，真实权限失败仍单独展示。
