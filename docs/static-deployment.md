# 静态边栏部署与宿主验收

当前项目为 Vite 纯前端，无渲染 API、数据库服务、Blob 服务或服务端密钥。Vercel 只托管静态 HTML、JavaScript、CSS、示例图片及字体。`vercel.json` 输出目录为 `dist`，不配置 Functions。

## 构建与发布

```sh
npm ci
npm run verify:static
npm run test:browser
npm run pack
```

Vercel 选择 Vite，构建命令 `npm run build`，输出目录 `dist`。不要设置 `RENDER_API_KEY` 或 `BLOB_READ_WRITE_TOKEN`。`npm run pack` 生成 `output/poster-sidebar.zip`。

## 缓存与安全头

- `/assets/*` 是构建 hash 文件，使用一年 immutable 缓存。
- HTML 使用 `max-age=0, must-revalidate`，字体缓存一周。
- CSP 只允许自身脚本、blob 资源及明确的飞书/Lark 域名；样式允许必要的 inline style。`frame-ancestors` 只允许自身和飞书/Lark 宿主。
- 启用 `nosniff`、严格同源 referrer 和基础 Permissions-Policy；没有外部遥测端点。
- 若宿主实际附件域名、SDK 行为或 iframe 与 CSP 不兼容，先按真实失败域名最小化补齐并复验，不能直接放开 `*`、`unsafe-eval` 或关闭 CSP。

## 多维表存储

- 启动时分别选择业务表和配置表，Base 内持久化连接指针。复用配置表只补两列文本字段，只有明确新建才建表。
- 固定模板存 `招聘海报模板`；来源模板存来源记录的 `海报模板配置`（文本）与 `海报字体`（附件）。
- 配置按业务 tableId 保存模板 ID、底图字段、输出字段和 `updatedAt` 乐观修订。保存后回读。
- 查找引用按来源表/字段元数据与附件 token 唯一定位，不能按文件名、临时 URL 或行顺序猜测。
- 工作区首屏分页读取记录；全表只在用户明确选择后按需读取并二次确认。
- 写回只替换目标附件单元格。上传与单元格写入串行；读取可以并行，写入完成才失效相关缓存。
- 模板包 ZIP 保留 JSON 和原始素材字节；本地 IndexedDB 使用 ArrayBuffer 并兼容旧 Blob。

## 真实宿主发布门禁

以下项目必须人工或通过运维验收环境执行；本地示例和 Mock SDK 不算真实验收：

1. **连接与权限**：桌面端和浏览器分别打开；新建/复用配置表、权限不足、字段类型错误均显示正确结果，不自动换表或回退示例。
2. **字段与来源**：首屏直接显示当前主记录及完整字段值，顺序与 `getFieldMetaList()` 返回数组一致；核对文本/数字 `0`/选项/电话/URL、附件文件名、附件 Lookup、空附件、多附件、重复来源 token、来源字段被删除。再进入“高级编辑 → 字段映射”验证文字、底图和输出绑定。
3. **模板与字体**：固定/来源模板保存回读、重开恢复、外部修订冲突、WOFF/WOFF2/OTF/TTF 解码、ZIP 导入导出均验证。
4. **写回边界**：单条、一键仅未写回、勾选、全表、停止、失败重试、结果未知和附件冲突均核对；一键扫描应跳过已有附件，全部已写回时不启动任务。只改变目标单元格，其他字段不变。全表任务注意网关限流，保持串行写入。
5. **异步目标**：任务发起后切换记录或表不能改变快照中的表、记录、字段和模板；当前选中行与批量勾选不混淆。
6. **输出一致性**：检查 PNG 尺寸、字体、长文本、颜色、位置、背景裁切及当前记录附件下载；临时 URL 不应出现在持久配置或日志中。
7. **部署兼容**：HTTPS、附件 CORS、CSP、iframe、Worker、缓存头及更新后 HTML/旧 chunk 不串版。若 CSP 阻断真实资源，按域名和浏览器控制台逐项修正并回归。
8. **并发与冲突**：两个窗口同时保存模板/配置或修改输出附件时，应出现修订/附件冲突提示；乐观检查不当作跨端原子锁。

## 当前自动化证据与限制

- Chromium：27 项通过，含记录首页与高级编辑的桌面/窄屏 axe、字段顺序、三层导航、PNG 基线、模板包、批量、记录与图层交互。
- WebKit：27 项通过，额外验证 ArrayBuffer 持久化与 ResizeObserver 调度。
- Firefox：本机二进制可执行，但 Playwright 在 profile 创建阶段连续失败，尚未完成浏览器验收；CI 保留该矩阵任务。
- 真实飞书宿主与 Vercel 部署尚未由本轮自动化验证，发布前必须完成上述门禁。
